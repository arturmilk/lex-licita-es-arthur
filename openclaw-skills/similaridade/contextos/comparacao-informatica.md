# Contexto: Comparação — Informática

Use este contexto quando a categoria do objeto for "informatica".

## Hierarquia de compatibilidade técnica

### Processador
- **Equivalente**: i5 ↔ Ryzen 5 (mesma faixa de performance)
- **Superior aceito**: i7/i9 ou Ryzen 7/9 quando desejado é i5
- **Inferior rejeitado**: i3 ou Ryzen 3 quando desejado é i5
- **Geração**: 12ª gen Intel ≈ Ryzen 5000 series. Gerações muito antigas (8ª gen Intel, Ryzen 2000) são inferiores.

### Memória RAM
- **Equivalente**: 16GB DDR4 ↔ 16GB DDR5 (capacidade igual)
- **Superior aceito**: 32GB quando desejado é 16GB
- **Inferior rejeitado**: 8GB quando desejado é 16GB
- **Tipo**: DDR5 é superior a DDR4, mas DDR4 ainda é compatível.

### Armazenamento
- **Equivalente**: 256GB SSD ↔ 256GB NVMe
- **Superior aceito**: 512GB SSD quando desejado é 256GB
- **Inferior rejeitado**: 128GB quando desejado é 256GB
- **HDD vs SSD**: HDD é inferior. Se desejado é SSD, HDD é incompatível.

### Tela
- **Equivalente**: 14" ↔ 14,1" (diferença irrelevante)
- **Compatível**: 13,3" ou 15,6" quando desejado é 14" (pequena variação)
- **Incompatível**: 11" ou 17" quando desejado é 14" (muito diferente)
- **Resolução**: Full HD (1920x1080) é padrão. 4K é superior. HD (1366x768) é inferior.

### Sistema Operacional
- **Equivalente**: Windows 11 Pro ↔ Windows 11 Enterprise
- **Compatível**: Windows 10 Pro quando desejado é Windows 11 Pro (ainda suportado)
- **Incompatível**: Windows Home quando desejado é Pro (faltam recursos corporativos)
- **Linux**: Ubuntu/Red Hat são compatíveis se o desejado mencionar "ou equivalente"

### Garantia
- **Equivalente**: 3 anos ↔ 36 meses
- **Superior aceito**: 5 anos quando desejado é 3 anos
- **Inferior rejeitado**: 1 ano quando desejado é 3 anos
- **On-site vs carry-in**: On-site é superior, mas carry-in é compatível.
