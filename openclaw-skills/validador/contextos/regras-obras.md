# Contexto: Regras — Obras

Use este contexto quando a categoria do objeto for "obras".

## Regras adicionais especificas de obras

### 8. BDI declarado
- **Padrao**: alertar se BDI nao for mencionado nas referencias
- **Info**: se BDI nao for mencionado
- **Mensagem": "Beneficios e Despesas Indiretas (BDI) nao especificados."
- **Recomendacao": "Verifique se o preco inclui BDI ou se e preco de custo direto."

### 9. Projeto executivo
- **Padrao**: alertar se referencias nao mencionarem projeto
- **Info**: se projeto nao for mencionado
- **Mensagem": "Nenhuma referencia menciona projeto executivo."
- **Recomendacao": "Obras sem projeto executivo podem ter variacao de custo significativa."

### 10. Mao de obra
- **Padrao**: alertar se regime de mao de obra nao for mencionado
- **Info**: se mao de obra nao for especificada
- **Mensagem": "Mao de obra (propria ou terceirizada) nao especificada."
- **Recomendacao": "O regime de mao de obra afeta o custo e a responsabilidade trabalhista."
